隱私權政策

生效日期：2026 年 11 月 1 日

本政策說明「江湖鏢局」Discord 機器人（顯示名稱：喵喵仙人）與 ASC 鏢局網站（以下合稱「本服務」）會收集哪些資料、怎麼使用與保存。本服務由 Chase.Tseng（以下稱「作者」）提供。

1. 我們收集的資料

  • Discord 帳號資料：使用者 ID、使用者名稱、頭像（只用來顯示），以及你在使用本服務的伺服器裡的身分組（用來判斷權限與發放身分組）。
  • 遊戲資料：鏢銀、修為與等級、簽到與值勤紀錄、道具、江湖歷練（RPG）角色與裝備、每日任務進度、陣營、賽季點數、抽獎參加紀錄。
  • 邀請紀錄：晉升任務「廣結群雄」會記錄你邀請了哪些成員加入。
  • 訊息：機器人會讀取伺服器設定的聊天頻道訊息來累積修為，只計算次數，不儲存訊息內容。若伺服器管理員開啟「跨服監聽」，指定來源頻道的訊息（作者名稱、內容、附件連結）會被轉發到目標頻道並暫存。
  • 錢包資料：你綁定的錢包地址（用簽名驗證，不需要也不會取得私鑰）、綁定時間、金庫驗證與白名單紀錄、被盜回報紀錄、點數兌換申請。
  • 網站：網站不使用追蹤用的 cookie 或分析工具。只在你的瀏覽器裡（localStorage）記住你選的語言；連結錢包時網站會看到你的公開錢包地址，並直接讀取區塊鏈上的公開資料。

2. 資料的用途

  • 提供本服務的功能，例如遊戲、排行、身分組、錢包綁定、白名單與點數兌換。
  • 防止作弊、重複領取與被盜錢包濫用。
  • 維護與改善本服務。

我們不會販售你的資料，也不會把資料用於廣告。

3. 資料保存在哪裡

  • 機器人與資料庫架設在 Railway 的雲端主機（美國），並定期備份到作者的私人 GitHub repository。
  • 網站放在 GitHub Pages。
  • 錢包地址與鏈上交易本來就公開記錄在 Polygon 區塊鏈上。

4. 與第三方分享

除了提供服務所需的服務商（Discord、Railway、GitHub、區塊鏈節點服務）以及法律要求的情況外，我們不會把你的資料提供給第三方。

5. 保存期間與刪除

  • 遊戲與綁定資料會保存到你要求刪除，或本服務停止為止。
  • 你可以來信 chase5ws@gmail.com，附上你的 Discord 使用者 ID，要求查詢或刪除你的資料；我們會在合理時間內處理。刪除後，相關的遊戲進度將無法恢復。
  • 寫在區塊鏈上的資料（例如 NFT 持有、交易紀錄）無法由任何人刪除。

6. 兒童隱私

本服務不針對未達 Discord 最低使用年齡的兒童。若發現收集了這類使用者的資料，我們會刪除。

7. 政策修改

本政策若有修改，會公布在本頁並更新生效日期。

8. 聯絡方式

任何隱私相關問題，請來信 chase5ws@gmail.com。

ENGLISH SUMMARY

Privacy Policy (summary)

  • What we collect: your Discord user ID, username, avatar and server roles; game data (coins, cultivation level, check-ins, items, RPG character, quests, faction, season points, raffle entries); who you invited (for the invite quest); bound wallet addresses (verified by signature, we never get your private key) and related verification, whitelist, stolen-wallet and redemption records.
  • Messages: the bot reads messages in the configured chat channels only to count them for cultivation; message content is not stored. If a server enables cross-server relay, messages from the chosen source channels (author name, content, attachment links) are relayed and stored temporarily.
  • Website: no tracking cookies or analytics; your language choice is kept in your browser's localStorage; when you connect a wallet the site sees your public address and reads public blockchain data.
  • Use and sharing: only to run and protect the service; never sold or used for ads; shared only with the providers that run it (Discord, Railway, GitHub, blockchain node services) or when required by law.
  • Storage: Railway cloud hosting (US) with backups in a private GitHub repository; the website is hosted on GitHub Pages. On-chain data is public and cannot be deleted.
  • Your choices: email chase5ws@gmail.com with your Discord user ID to access or delete your data.
